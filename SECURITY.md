# Security reports

Do not post credentials, provider responses, chat logs, application databases or unredacted screenshots in public issues.

Report suspected credential exposure or other vulnerabilities through [GitHub's private vulnerability reporting](https://github.com/Rasalas/juicebar/security/advisories/new). Include the Juicebar version, macOS version and a minimal reproduction using synthetic data when possible.

This is an early community project. There is no paid incident-response agreement or guaranteed response time. Security and compatibility fixes are distributed without an additional payment requirement.
