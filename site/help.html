Setup & help.

Juicebar uses the tools and accounts you already have. It does not require a separate account or send prompts to check your limits.

Install on your Mac

  1. Download Juicebar 0.1.4 for Mac. The current build requires Apple Silicon and macOS 14 or later.
  2. Open the disk image and drag Juicebar to Applications. Eject the disk image, then open Juicebar from Applications.
  3. Open Accounts and connect your providers. Enable notifications under Warnings when you are ready.

The official direct download is Developer ID signed and notarized. You should not need to disable Gatekeeper. Source builds are a separate option for contributors.

Connect a provider

ChatGPT / Codex subscription

Install the Codex CLI and run codex login in Terminal. Choose your ChatGPT account. In Juicebar, add Codex and save. CLI paths are detected automatically; a custom program or profile folder can be set under Advanced setup.

Claude subscription

Install Claude Code and run claude auth login. Add Claude in Juicebar and save. The CLI must be signed in to the subscription you want to monitor. A browser-only sign-in is not enough.

OpenCode Go

Choose the correct account and workspace in the OpenCode console. Juicebar can read an existing local opencode-go API key, or you can save a Go key in its account form. The form tells you when it finds a local key.

The newer opencode console login session is not yet a supported source for this quota integration. A 403 or EntitlementError means the key does not report Go access; check its workspace and subscription assignment. It does not, on its own, prove your paid subscription expired.

OpenCode Zen and API accounts

Zen activity comes from the local OpenCode database. Juicebar does not currently claim a verified Zen balance. OpenAI and Anthropic organization cost reports require an admin key; a normal model API key is not enough. OpenRouter uses a management key for account-wide balance.

These are separate from ChatGPT and Claude subscriptions. A budget entered in Juicebar is your warning budget, not a provider-imposed cap.

Understand the numbers

Why is a quota line flat?

Quota history records provider measurements from the time Juicebar starts collecting them. A flat line means the reported percentage did not change. Token logs cannot reconstruct subscription percentages.

Where does the API cost come from?

Juicebar estimates the API equivalent of recorded input, output and cache tokens at current standard prices. It shows coverage and leaves unknown models unpriced. This is not what you paid for a subscription. Confirmed model aliases and prices can update through a signed data catalog. That check can be disabled in Settings.

Why are older chats or dates missing?

Usage imports automatically at launch and every five minutes. Available local and SSH logs cover up to 90 days. Logs deleted before the first import, unconnected devices and browser-only chats may be absent. Older Claude daily statistics can fill gaps, but often lack enough detail for a cost estimate.

How do I add another computer?

Under Usage, add an existing SSH alias such as workstation. The host needs Python 3, a known host key and working key-based login. Juicebar rejects password prompts and does not install anything remotely. Only usage metadata is returned.

Notifications appear only in Notification Center

Allow Juicebar banners and sound in macOS System Settings → Notifications. Check Focus and screen-sharing settings too. Then enable notifications and sound inside Juicebar and send a test notification. macOS controls whether a banner can appear.

Will updates cost money?

No. Direct downloads and their updates stay free. Mac App Store distribution is on hold while equivalent, provider-compliant integrations remain unresolved.

Something still looks wrong?

Open an issue with your macOS version, Juicebar version, provider and what you expected to see. Redact account names from screenshots and never attach API keys, credentials or raw conversation logs.

For a security issue, use private vulnerability reporting.
