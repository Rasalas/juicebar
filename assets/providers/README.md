# Anbieterzeichen

OpenAI-Knoten, Claude-Stern und OpenCode-Zeichen aus den Brand-Assets von [T3 Code](https://github.com/pingdotgg/t3code/tree/d06f0ff1048d42a156824765316c5a2dc54f5bca/apps/marketing/public/harnesses). Lizenzkopie: `LICENSE-T3`. Die Zeichen identifizieren die jeweiligen Anbieter; Juicebar ist kein offizielles Produkt dieser Unternehmen. Markenrechte bleiben bei den Inhabern.

Die SVG-Originale werden mit macOS `sips -s format png` in die gebündelten PNG-Ressourcen umgewandelt. Die App verwendet ihre Silhouette als Template, für Codex in Blau, für Claude in Terrakotta und für OpenCode neutral. Keine Downloads zur Laufzeit.
